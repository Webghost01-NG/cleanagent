# 🤖 CleanAgent Protocol — Next.js 16 Web3 Application

> **Autonomous AI Yield Management & CVI Counterparty Compliance Engine**  
> *Target Chain: Monad Testnet (Chain ID 10143)*

---

## ⚡ Overview

This is the Next.js 16 App Router application for **CleanAgent Protocol**. It features:
- **Natural Language AI Console**: Interactive AI assistant generating smart mandates and processing CVI identity queries.
- **Mandate Control Panel**: Real-time spend limits ($25k default cap) & APY yield floor controls.
- **In-App Monad CVA Audit Inspector**: 1-click 66-character EVM cryptographic provenance modal.
- **Web3 Wallet Integration**: Native EVM (MetaMask) & Solana (Phantom) wallet gating.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Next.js development server
npm run dev
```

Open **`http://localhost:3000`** in your browser.
